# System Architect Library

Static reading library for System Architect (SA) examination knowledge and design decisions.

## Development

```sh
npm install
npm run dev
npm run build
```

Deployment target: GitHub Pages at https://yohn-jp.github.io/sa-architecture-library/ . Set repository **Settings → Pages → Source** to **GitHub Actions**.

The initial publication is **not complete** until the existing original textbook HTML is placed at `public/complete/index.html`. See [architecture](docs/ARCHITECTURE.md).
