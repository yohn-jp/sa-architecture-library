# 午後Ⅰ CBT型記述演習 — 正本実装契約

## 対象

IPAシステムアーキテクト試験の午後Ⅰ、2016～2019年度・2021～2025年度の9回・34大問・322解答欄。午前Ⅱと同じ試験回を収録。学習者はPCで問題PDFを読み、2問を選び、90分で記述する。採点・AI評価は行わない。

- 問題冊子はIPA公式PDFを改変せず public/practice/pm1/pdfs/<id>.pdf としてGitに保存する。設問テキストのOCR結果は出題本文として表示しない。
- 解答欄は src/data/pm1-fields.json を正本とし、年度＋問＋安定した欄IDで自動生成する。230欄に問題冊子で指定された字数上限を設定し、数値の字数指定がない92欄（属性名・記号等）は null。数値を創作しない。複数回答は別欄に分ける。超過時は警告し、答案自体を切り捨てない。
- 公式解答例はIPA公式解答例PDFの埋込テキストを抽出し、原本の表セルを設問に結び付けた src/data/pm1-official-answers.json を使用する。閲覧時にOCR処理や外部API呼出しを行わない。試験中は解答例を表示しない。終了後に自分の答案／IPA公式解答例を文字列で左右比較し、PDF原本の該当ページも明示する。
- 出典と監査用に src/data/pm1-sources.json、public/practice/pm1/pdfs/manifest.json、src/data/pm1-audit/<id>.json（問題OCR・解答例抽出・位置）、src/data/pm1-tables/<id>.json（公式解答表）、src/data/pm1-structured/<id>.json（設問IDと解答の対応）を保持する。public/practice/pm1/answers/<id>.pdf は解答例の原本検証用であり、通常の画面で埋込表示しない。通常ビルドでPDFを取得しない。

## 回答データと保存

src/lib/pm1-session.ts により sa-pm1-session-v1:<year> を維持する。年度・問・欄IDで対応させ、既存の入力を削除しない。従来形式の保存済み途中セッションには公式欄を追加し、旧入力欄をそのまま残す。終了済み答案は変更せず、表示側で旧記述を別枠に保持する。旧記述を公式欄の解答に推測で紐付けない。公式欄の名称・字数上限は固定で、追加メモのみ自由編集可能。

タイマーは開始時の絶対時刻から90分を算出し、ブラウザを閉じても進行する。終了後・期限切れは読み取り専用。localStorage依存のためブラウザ消去等での消失や端末間同期には対応しない。

## 検証契約

ビルド時に全9年度・34大問・322欄、公式解答例との完全一致する欄ID・名称、230欄の字数上限、原本PDF18冊（問題9＋解答9）のSHA-256を検証する。E2Eは9年度の2問選択、記述、超過表示、保存、再開、終了後の公式解答例表示、旧セッション移行を確認する。元の午前Ⅱ225問と読書画面の回帰を維持する。OCRと原本PDFの更新は新年度追加時などに明示実行し、通常の公開では行わない。
