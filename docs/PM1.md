# 午後Ⅰ CBT型記述演習 — 実装契約

## 目的と非目的

2023〜2025年度のIPA公式システムアーキテクト午後Ⅰ問題冊子をPC上で読み、2問を選んでキーボードだけで記述練習する。公式CBTの完全なUI再現を謳わない。

**対象**: 年度選択、2問選択、90分タイマー、同一サイトの公式PDF表示、問題別の記述欄（追加・削除・名称・文字数上限編集可能）、ブラウザ内の自動保存・再開、終了後の答案確認。

**対象外**: IPA採点の再現、自動採点、AI採点、ユーザー認証、データ同期、問題本文の転記・再構成。PDFの設問を読んだうえでユーザーが必要な回答欄を設定する。文字数上限はユーザーが設定した値であり、IPA公式の設問制約を自動抽出したものではない。

## 信頼できる資料

src/data/pm1-sources.json にIPA公式の配布ページ・問題冊子URL・ページ数・出題数を保持する。public/practice/pm1/pdfs/<year>.pdf は原本をバイナリのままコミットする。public/practice/pm1/pdfs/manifest.json に各PDFのダイジェストを記録する。

python3 scripts/fetch_pm1_pdfs.py は新しい年度を追加する際に**明示的に一度だけ**実行するためのツール。通常の npm run build や Pages Actions はネットワークから午後ⅠのPDFを取得しない。scripts/verify_site.py はコミットされたPDFのハッシュ・サイズ・ページメタデータを検証し、不一致の場合は公開を止める。

## セッション

src/lib/pm1-session.ts が唯一の保存・入力検証の責務を持つ。保存キーは sa-pm1-session-v1:<year> で年ごとに分離する。タイマーは壁時計の絶対時刻から計算し、画面を閉じても進む。90分経過で書込みを終了し、状態を確定する。終了後の答案は読み取り専用。新規受験時は確認後に当該年度のみ上書きする。

問題と答案の連結は「年度・問番号・解答欄ID」で行う。PDFには改変を加えない。ページ内にユーザーの答案を埋め込まず、同一サイトの別ペインに表示する。データは端末・ブラウザ単位であり、消去、プライベートモード、ストレージ制限では保持を保証できない。

## 検証

- コンテンツ: PDF3冊の署名・実ページ数・SHA-256、IPA配布URLと収録一覧の整合。
- ブラウザ: 年度選択、2問制限、PDF表示リンク、記述欄追加・削除、文字数警告、localStorage保存・リロード・復帰、別タブ更新、タイマー満了、終了後の読み取り専用表示。
- 回帰: 午前Ⅱの年度別・ランダム演習と復習、40章の原本ハッシュ検証を維持。
- 解答例と採点講評はスコープ外。ユーザーに誤った採点結果を提示しない。
